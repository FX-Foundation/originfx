OriginFX - first-run setup (steps 1 to 3)

Run:   ./originfx
Needs: fontconfig and freetype. On an X11 session (not Wayland) it also needs
       libxkbcommon-x11, which Ubuntu, Fedora and Debian desktops already include.
       If it is missing:  sudo apt install libxkbcommon-x11-0

Your choices are saved to ~/.config/OriginFX/setup.json
